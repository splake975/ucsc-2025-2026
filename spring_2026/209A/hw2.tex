\begin{enumerate}
  \item 
  instantiate an \(n\times n\) matrix \(A\) of all zeros. 
  \item 
  for each node \(i\), choose two distinct nodes \(j,k\) that \(i\) is connected to. increment the \(A_{j,k}\) by 1. 
  \item 
  if any entry in \(A\) is greater than 2, then there exists a cycle. 
\end{enumerate}

\textbf{runtime:}

each item above takes \(n^2\) time and are not nested thus the runtime is \(n^2\). 

\textbf{correctness:}

\(A_{i,j}\) can only have an entry greater than two iff at least two distinct vertices \(\alpha,\beta\) are neighbors to both \(i,j\). This means there is a 4 cycle on \(i,\alpha,j,\beta\). 

on vertex \(a\), each loop searches for all possible wedges with center point \(a\) and increments the entry corresponding to the endpoints of the wedge. In the language of loop invariants, after each loop in item 2, the value of \(A_{i,j}\) counts the number of wedges with endpoints \(i,j\) that can be formed using only verticies before the index of the loop. 

in the end, since every possible center point of wedges was checked, \(A\) exactly counts the number of wedges with endpoints \(i,j\). two wedges with distinct center points must mean there is a cycle of length 4.
