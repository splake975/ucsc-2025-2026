\section{Definitions}

For a function \(f:[n]\to \mathbb R\) we say a pair \((i,i+1)\) for \(i\) in \([n-1]\) is 
\begin{enumerate}
    \item a \emph{good pair} if there exists an optimal LIS that uses both elements in the pair
    \item a \emph{bad pair} if no optimal LIS includes both elements in the pair
    \item a \emph{perfect pair} is a pair that must be used in all optimal LIS
\end{enumerate}

Note that all \((j,j+1)\) such that \(f(j)>f(j+1)\) are "bad pairs". Also note that all perfect pairs are also good pairs

\subsection{padding good pairs}

Consider the construction of a new function 
\(f_p:[n+1]\to \mathbb R\) defined as \begin{equation}
        f_p(x) = \begin{cases}
            f(x),& x\leq i\\
            \frac{f(i)+f(i+1)}{2},& x=i+1\\
            f(x+1),&x\geq i+2
        \end{cases}
    \end{equation}

\begin{theorem}
    given a function \(f\) and a good pair of \(f\) \((i,i+1)\), \(f_p\)
    forces \((i,i+1),(i+1,i+2)\) to both be perfect pairs in the new function \(f_p\).
    Additionally, \(f_p\) has a distance to monotonicity of \(\frac{\varepsilon_fn + 1}{n+1}\)
    
    % adding an additional value between \(i,i+1\) that respects monotonicity results in \((i,i+1),(i+1,i+2)\) to become perfect pairs. 
\end{theorem}
