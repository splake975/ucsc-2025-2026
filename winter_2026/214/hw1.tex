\begin{enumerate}
    \item consider the relations \(G^\prime\) describing graph \(G\) where the schema is source and terminal nodes for edges. (G can be directed).

    the k clique problem would be 
    \begin{equation}
        \exists x_1 \dots \exists x_k \bigwedge_\text{ over all combinations of $x_i$,$x_i'$ } G^\prime(x_i,x_i')
    \end{equation}

    note that this conversion takes approx \(n^2\) time to complete. \({n\choose 2}\approx n^2\) asymptotically

    this shows this problem is np hard. 
    to show this problem is in np, a polynomial time verifiable certificate could be the exact set \(\{x_1\dots x_k\} \) such that the formula comes out true. this can be verified in polytime of the input because each clause takes at most O(1) to verify since we know there are only two arguments. 
    \item this problem is now in P. given there are \(n\) clauses and \(m\) different elements in the domain and \(a\) variables, we can break the query into \(a\) single variable queries. each element in the domain takes at most \(n\) attempts per query. in total it would take \(a m n\) time which is in \(\mathbb P\).
\end{enumerate}
